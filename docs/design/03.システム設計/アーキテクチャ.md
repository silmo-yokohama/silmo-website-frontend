# SilMoポートフォリオサイト アーキテクチャ

このドキュメントでは、SilMoポートフォリオサイトの全体アーキテクチャとディレクトリ構成について定義しています。

## 1. アプリケーションアーキテクチャ

### 1.1 全体アーキテクチャ

```text
+--------------------+     +--------------------+     +--------------------+
|                    |     |                    |     |                    |
|   クライアント      |<--->|   Nuxt3 アプリ     |<--->|   Newt (CMS)       |
|   (ブラウザ)        |     |                    |     |                    |
|                    |     |                    |     |                    |
+--------------------+     +--------------------+     +--------------------+
                                    ^
                                    |
                                    v
                           +--------------------+
                           |                    |
                           |   Google Analytics |
                           |                    |
                           +--------------------+
```

### 1.2 アーキテクチャの特徴

- **JAMstackアーキテクチャ**: 静的生成（SSG）を基本としつつ、必要に応じてSSRを活用
- **ヘッドレスCMS連携**: API経由でコンテンツを取得し、ビルド時に静的ページを生成
- **サーバーサイドレンダリング（SSR）**: 一部ページでは必要に応じてSSRを活用
- **Vue Composition API**: Vue 3の機能を活かした効率的なコンポーネント開発
- **Nuxt Nitro**: 高性能なサーバーエンジンを活用したコンテンツ配信

## 3. 開発ツールとワークフロー

### 3.1 開発環境

- **ローカル開発**: `npm run dev` でNuxt開発サーバーを起動
- **コンポーネント開発**: `npm run story` でStorybookを起動し、コンポーネント単位での開発・テストを実施
- **型チェック**: `npm run type-check` でTypeScriptの型チェックを実施
- **リンター**: `npm run lint` でESLintによるコード品質チェックを実施
- **フォーマッター**: `npm run format` でPrettierによるコードフォーマットを実施

### 3.2 テスト環境

- **ユニットテスト**: `npm run test` でVitestによるユニットテストを実行
- **カバレッジ確認**: `npm run test:coverage` でテストカバレッジを確認
- **UI**: `npm run test:ui` でVitestのUIモードを起動

### 3.3 ビルドと配布

- **静的サイト生成**: `npm run generate` でNuxtのSSG機能を利用して静的サイトを生成
- **サーバーサイドレンダリング**: `npm run build` でSSR用のビルドを実施
- **プレビュー**: `npm run preview` でビルド結果のプレビューを確認
