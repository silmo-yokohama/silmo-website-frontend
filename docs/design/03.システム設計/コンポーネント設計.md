# SilMoポートフォリオサイト コンポーネント設計

このドキュメントでは、SilMoポートフォリオサイトのコンポーネント設計方針、主要コンポーネント、およびコンポーネントの再利用戦略について定義しています。

## 3. コンポーネント設計

### 3.1 基本方針

- **原子設計（Atomic Design）**: UI要素を段階的に組み合わせるコンポーネント設計手法を採用
- **コンポーネント単位の責任分離**: 各コンポーネントは単一の責務を持つよう設計
- **Composition APIによる実装**: Vue 3のComposition APIを活用した宣言的UI実装
- **Props伝播の最適化**: 必要最小限のプロップスの伝達、必要に応じて`provide/inject`を活用

### 3.2 主要コンポーネント

#### レイアウトコンポーネント

- `app.vue`: アプリ全体のエントリーポイント
- `layouts/default.vue`: デフォルトレイアウト
- `components/layout/TheHeader.vue`: ナビゲーションメニューやブランド要素を含むヘッダー
- `components/layout/TheFooter.vue`: サイト共通のフッター情報
- `components/layout/TheContainer.vue`: コンテンツの配置を制御するコンテナ

#### 実績・成果物関連コンポーネント

- `components/works/WorkCard.vue`: 実績・成果物のカード表示コンポーネント
- `components/works/WorkGrid.vue`: カードのグリッドレイアウト
- `components/works/WorkDetail.vue`: 詳細ページのレイアウト
- `components/common/TechBadge.vue`: 使用技術タグの表示
- `components/common/BasePagination.vue`: ページネーション制御

#### プロフィール関連コンポーネント

- `components/about/ProfileSection.vue`: プロフィール情報のセクション
- `components/about/SkillChart.vue`: スキルセットのグラフィカル表示
- `components/about/TimelineItem.vue`: 経歴表示のタイムライン要素

#### UI共通コンポーネント

- `components/ui/`: ベースとなるUIコンポーネント（Button, Card, Input など）
- `components/ui/ThemeToggle.vue`: ダークモード切替ボタン
- `components/ui/BaseAnimation.vue`: アニメーション効果を適用するラッパー

### 3.3 コンポーネント再利用戦略

- `utils/helpers.ts`に共通のヘルパー関数を定義
- Nuxt3のComposablesディレクトリにカスタムCompositionを配置
- スタイルの再利用はTailwind CSSのユーティリティクラスとカスタムSCSSを併用
- Nuxt3のAuto Importsを活用し、インポート文を最小化

### 3.4 Nuxt3コンポーネントの特徴

#### 単一ファイルコンポーネント（SFC）

- `<template>`, `<script>`, `<style>`ブロックを一つのファイルにまとめた構造
- `<script setup>`構文を活用した簡潔なコンポーネント定義
- `lang="ts"`属性によるTypeScript統合

#### コンポジション関数

- 再利用可能なロジックをCompositionとして抽出
- コンポーネント間での状態と振る舞いの共有
- 適切な名前付け規則（`use`プレフィックス）に従った実装

#### Nuxtモジュールとの連携

- `@nuxtjs/color-mode`などのモジュールを活用した機能拡張
- Nuxt固有の機能（`useAsyncData`, `useFetch`など）の適切な活用
