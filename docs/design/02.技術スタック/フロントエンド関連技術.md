# SilMoポートフォリオサイト フロントエンド関連技術

このドキュメントでは、SilMoポートフォリオサイトのフロントエンド基盤、スタイリング、アニメーション・UI/UXに関連する技術選定について定義しています。

## 1. フロントエンド基盤

| 項目             | 選定技術                 | バージョン | 選定理由                                                                                                                               |
| ---------------- | ------------------------ | ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| フレームワーク   | Nuxt                     | 3.15.4     | Vue.jsベースのフレームワーク。ファイルベースルーティング、自動インポート機能、SSR/SSG対応など、効率的な開発環境を提供。SEO対策も容易。 |
| 言語             | TypeScript               | 5.x        | 型安全性の確保、保守性・可読性向上。大規模開発における堅牢性担保。                                                                     |
| ステート管理     | Vue Composition API      | -          | Vue 3標準のComposition APIによるステート管理。コンポーネント内で完結する状態管理が可能。必要に応じてPiniaなどの導入も検討。            |
| ルーティング     | Nuxt Pages Router        | -          | 標準機能としてのファイルベースルーティング。動的ルート対応、パラメータ管理が容易。                                                     |
| レンダリング戦略 | ハイブリッドレンダリング | -          | SSG (Static Site Generation) を基本としつつ、必要に応じてSSR (Server Side Rendering) を活用。Nuxt Nitroエンジンによる最適化。          |

## 2. スタイリング

| 項目              | 選定技術               | バージョン | 選定理由                                                                                     |
| ----------------- | ---------------------- | ---------- | -------------------------------------------------------------------------------------------- |
| UIコンポーネント  | カスタムコンポーネント | -          | プロジェクト要件に合わせたカスタムUIコンポーネントを開発。再利用性とアクセシビリティを重視。 |
| CSSフレームワーク | Tailwind CSS           | 3.4.17     | ユーティリティファーストで開発効率向上。JITモードによるバンドルサイズ最適化。                |
| CSSプリプロセッサ | SCSS                   | 1.83.4     | 変数管理や入れ子構造などの高度な機能を活用。Tailwind CSSと併用し柔軟なスタイリングを実現。   |
| カラーモード      | @nuxtjs/color-mode     | 3.5.2      | ダークモード実装のためのNuxtモジュール。システム設定との連携、切替時の状態管理を容易に実現。 |
| アイコン          | Lucide Vue Next        | 0.474.0    | モダンでカスタマイズ性の高いアイコンセット。Vue 3との互換性に優れる。                        |

## 3. アニメーション・UI/UX

| 項目               | 選定技術              | バージョン | 選定理由                                                                                           |
| ------------------ | --------------------- | ---------- | -------------------------------------------------------------------------------------------------- |
| アニメーション     | Vue Transitions + CSS | -          | Vue組み込みのトランジション機能とCSSアニメーションの組み合わせ。必要に応じてGSAPなどの導入も検討。 |
| ページ遷移         | Nuxt Page Transitions | -          | Nuxt組み込みのページトランジション機能。UXの向上とスムーズな画面遷移を実現。                       |
| インタラクティブUI | Vue Composition API   | -          | リアクティブな状態管理とリッチなインタラクションを実装。フォーム実装の簡素化。                     |
| ローディング状態   | Nuxt Loading API      | -          | ページ遷移時のローディング表示。UXの向上、不可視時間の削減。                                       |
