# SilMoポートフォリオサイト スタイリング規約

このドキュメントでは、SilMoポートフォリオサイトのCSSおよびスタイリングに関するルールについて定義しています。一貫したスタイリングと効率的な開発を促進するためのガイドラインです。

## 6. スタイリングルール

### 6.1 基本戦略

- **Tailwind CSSベース**: ユーティリティファーストのアプローチを主として採用
- **SCSS拡張**: 必要に応じてSCSSで変数やミックスインを定義
- **BEMの考え方**: カスタムクラスが必要な場合はBEM（Block、Element、Modifier）命名規則を採用
- **コンポーネントスコープ**: Vueの`<style scoped>`を活用してコンポーネント内でのスタイル適用範囲を制限

### 6.2 Tailwind CSS

- **ユーティリティクラス**: Tailwindのユーティリティクラスを積極的に活用
- **カスタマイズ**: `tailwind.config.ts`でテーマのカスタマイズを行い、一貫性を保つ
- **プラグイン**: 必要なTailwindプラグイン（typography, forms, aspect-ratioなど）を適宜活用
- **JITモード**: Just-in-Timeモードによる最適化を活用

### 6.3 SCSSの利用

- **変数定義**: グローバル変数は`assets/scss/_variables.scss`に定義
- **ミックスイン**: 再利用可能なスタイルパターンはミックスインとして定義
- **カスケーディング**: 深いネスティングは避け、必要最小限のセレクタ階層を維持
- **Tailwindとの併用**: TailwindのユーティリティクラスとSCSSを効果的に組み合わせる

```scss
// 変数の例
$primary-color: #4a6cf7;
$secondary-color: #27ae60;
$transition-base: all 0.3s ease-in-out;

// ミックスインの例
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

@mixin responsive-font($min, $max) {
  font-size: clamp(#{$min}px, 4vw, #{$max}px);
}
```

### 6.4 Vueコンポーネントでのスタイル

- **スコープ付きスタイル**: `<style scoped>`を使用してスタイルをコンポーネント内に閉じ込める
- **グローバルスタイル**: グローバルなスタイルは`assets/scss/main.scss`に定義
- **CSSモジュール**: 必要に応じて`<style module>`を使用してCSS Modulesを活用
- **深い階層へのスタイル適用**: 必要な場合は`:deep()`セレクタを使用

```vue
<style scoped>
  .card {
  @apply rounded-lg shadow-md p-4;
}

/* 子コンポーネントの要素にスタイルを適用 */
:deep(.card-title) {
  @apply text-xl font-bold mb-2;
}
</style>
```

### 6.5 レスポンシブデザイン

- **モバイルファースト**: モバイル向けスタイルをベースとし、メディアクエリで拡張
- **Tailwindブレークポイント**: Tailwindの標準ブレークポイントを活用（sm, md, lg, xl, 2xl）
- **コンテンツに応じた調整**: 固定幅よりもコンテンツに応じた柔軟なレイアウトを優先
- **Flexボックス/Grid**: 最新のレイアウト技術を活用し、複雑なメディアクエリを回避

### 6.6 ダークモード対応

- **Nuxtカラーモード**: `@nuxtjs/color-mode`を活用したダークモード実装
- **カラーテーマ**: テーマごとの色変数を定義し、一貫したカラースキームを維持
- **自動検出**: ユーザーのシステム設定に基づく自動テーマ切り替えをサポート
- **テーマ切替**: スムーズなテーマ切り替えのためのトランジションを実装

```vue
<style>
  :root {
  --bg-color: #ffffff;
  --text-color: #333333;
}

.dark-mode {
  --bg-color: #121212;
  --text-color: #f5f5f5;
}

body {
  background-color: var(--bg-color);
  color: var(--text-color);
  transition: background-color 0.3s ease, color 0.3s ease;
}
</style>
```
