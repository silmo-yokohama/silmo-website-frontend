# SilMoポートフォリオサイト コーディング規約インデックス

このディレクトリには、SilMoポートフォリオサイトのコーディング規約に関するドキュメントが含まれています。プロジェクト全体で一貫した高品質なコードを維持するための基準と指針を定めたものです。

## ディレクトリ構成

- [基本方針と命名規則](./基本方針と命名規則.md) - コーディングの基本原則、命名規則、ファイル構成
- [TypeScript規約](./TypeScript規約.md) - TypeScript利用に関するルールとベストプラクティス
- [Vueコンポーネント規約](./Vueコンポーネント規約.md) - Vueコンポーネントの実装規約と設計指針
- [スタイリング規約](./スタイリング規約.md) - CSS、TailwindCSS、SCSSの利用ルール
- [コード品質と安全性](./コード品質と安全性.md) - テスト、エラー処理、セキュリティ、アクセシビリティなど

## 重要なポイント

- プロジェクト全体で一貫した命名規則とコードスタイルを維持
- TypeScriptの型システムを最大限に活用したタイプセーフな開発
- Vue 3のComposition APIとScript Setupを活用した効率的なコンポーネント開発
- TailwindCSSとSCSSを組み合わせた効率的でメンテナンス性の高いスタイリング
- 高品質なコードを維持するための自動テストと静的解析ツールの活用
